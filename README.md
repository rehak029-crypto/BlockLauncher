# BlockLauncher

A Minecraft: Java Edition launcher with a built-in visuals mod. Sign in with your own Microsoft account.

## Download

Get the latest version from **[Releases](../../releases/latest)**:

- **BlockLauncher.exe**: small download. Needs the free [.NET 10 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/10.0) (Windows asks you to install it the first time if it's missing).
- **BlockLauncher-full.exe**: bigger download with everything built in.

Put the exe in a folder you'll keep (for example Documents\BlockLauncher) and open it. It adds itself to the Start menu and updates itself when a new version comes out.

Windows may show "Windows protected your PC" because the app isn't signed. Click **More info → Run anyway**.
